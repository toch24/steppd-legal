SMS opt-in

How people agree to receive text messages from Steppd

Steppd is an iOS app. It has no password or email login: people sign up and log in with their mobile number, and Steppd texts them a one-time verification code to confirm the number is theirs. These verification codes are the only text messages Steppd sends. There are no marketing or promotional messages.

Where people opt in

Opt-in happens on the phone-number screen of the Steppd iOS app, which every user reaches when they create an account or log in. The screens below are exactly what they see, and both show the same disclosure.

  1. The user opens Steppd and taps Create account or I already have an account.
  2. On the next screen they type their mobile number. Directly below the number field the screen shows the disclosure quoted below, with links to the Terms and the Privacy Policy.
  3. The user taps Text me a code. Only then does Steppd send a text. If they don't tap it, no message is sent.

The disclosure shown on both screens

By tapping “Text me a code”, you agree to receive a one-time verification code by text from Steppd each time you sign up or log in. Msg & data rates may apply. Reply STOP to opt out, HELP for help. Terms and Privacy Policy.

Details

  • Consent is not forced or bundled. There is no pre-checked box, and nothing is sent until the user enters their own number and taps the button. Agreeing to receive texts is not a condition of anything other than receiving the code they asked for.
  • Message type: one-time verification codes only.
  • Frequency: one message each time the user asks for a code.
  • Sample message: “Your Steppd code is 123456”
  • Opt out: reply STOP. Help: reply HELP or email steppdapp@outlook.com.
  • Data: mobile numbers and text-messaging consent are not shared with third parties or affiliates for marketing or promotional purposes. See section 3 of the Privacy Policy.
